# EcoMed360 website delivery

This bundle contains the EcoMed360 source code and the verified production build.

## Run locally

```bash
npm ci
npm run dev
```

Available pages:

- `/`
- `/about`
- `/contact`
- `/sage`

## Build for production

```bash
npm run build
```

The deployable output is written to `dist/`. Contact forms use `info@ecomed360.ai`.
